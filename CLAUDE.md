## Task Tracking

For any work involving 3 or more steps, always create a task list with TaskCreate before
starting implementation. Mark each task `in_progress` when beginning it and `completed`
immediately when done. At the start of each session, check for existing tasks with TaskList
before creating new ones — this prevents forgetting agreed-upon items when context is lost
between sessions. If a multi-step feature is agreed upon in conversation but not yet
implemented, create the tasks before moving on.
